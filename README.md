# Numerasi — Platform Pembelajaran Numerasi untuk Pelajar SMP

## Tentang Proyek

Numerasi merupakan sebuah website pembelajaran yang dikembangkan sebagai solusi untuk membantu mengatasi permasalahan kemampuan numerasi pada pelajar Sekolah Menengah Pertama (SMP) di Indonesia.

Platform ini dirancang untuk menghadirkan pengalaman belajar numerasi yang lebih mudah diakses, interaktif, dan menarik. Melalui website ini, diharapkan pelajar dapat meningkatkan pemahaman serta kemampuan dalam menerapkan konsep matematika untuk menyelesaikan permasalahan sehari-hari.

Proyek ini dikembangkan berdasarkan ide, konsep, perancangan sistem, dan alur kerja yang dirancang oleh tim kami.

## Tech Stack

Teknologi yang digunakan dalam pengembangan proyek ini meliputi:

- React.js sebagai library untuk membangun antarmuka pengguna.
- Vite.js sebagai build tool dan development server.
- JavaScript sebagai bahasa pemrograman utama.
- CSS untuk mengatur tampilan dan desain website.

## Instalasi dan Menjalankan Proyek

Untuk menjalankan proyek secara lokal, pastikan Node.js dan npm sudah terinstal pada perangkat.

1. Clone repository proyek dari GitHub menggunakan perintah `git clone <repository-url>`.
2. Masuk ke direktori proyek menggunakan perintah `cd <nama-folder-proyek>`.
3. Jika frontend berada di dalam folder terpisah, masuk ke folder frontend menggunakan perintah `cd frontend`.
4. Install seluruh dependencies yang dibutuhkan dengan menjalankan `npm install`.
5. Jalankan development server menggunakan perintah `npm run dev`.
6. Buka browser dan akses alamat `http://localhost:5173` untuk melihat website secara lokal.
